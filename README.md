# 飞书群聊文件归档智能体（aILY V2）

飞书群聊中的文件归档机器人。用户回复目标文件消息并 @机器人发起归档 → 机器人精确读取被回复文件 → 用户确认文件 → 逐层选择目标目录 → 最终确认后上传到云盘指定位置。

## 技术栈

- **平台**：飞书 aILY（智能伙伴创建平台）
- **架构**：两个 aILY 技能（技能 A 接收消息 + 技能 B 处理卡片回调）
- **状态管理**：飞书多维表格（Base `WHaibyXvuaXuJpsDraJcAAM9nIb`）
- **交互**：4 张飞书卡片（确认文件 → 选目录 → 最终确认 → 结果）

唯一有效实施方案是 Aily V2 重搭版：技能 A 不读取整段群聊历史，也不使用智能体猜文件；它只处理用户明确回复的文件消息。技能 B 的每次卡片点击都是一次新运行，只能从开始节点全局参数进入，再通过 `request_id` 从“归档请求”多维表格恢复状态。即使只有一个文件，也必须先发送卡片 1，由用户明确确认。
